## 2026-11-14 讲解员（智能体）改进

针对设计评审列出的问题修改 `src/server.js` 与 `src/page.html`，知识库数据未改。

- **限流**：模型调用前按 IP 计数（问答每 10 分钟 30 次、规划 10 次）并限制每个实例每小时总量 600 次，超出返回 429；数值可用环境变量调整。计数只在单个实例内存中有效，不能替代模型服务账户侧的费用上限。
- **输出长度**：`max_tokens` 由 500 提高到 900，提示词要求回答不超过 300 字；模型输出因长度截断（`finish_reason: length`）时视为格式错误并重试。
- **问题分类**：模型先判断 history / chat / off_topic。问候、感谢、使用说明不再一律回复“资料不足”；自称闲聊却引用资料或含三位以上数字的回复，按历史问题处理。
- **数字核对**：历史回答中的阿拉伯数字必须出现在所引资料或用户问题中；不符时带校验提示重试一次，仍不符则降级为“资料不足”。该检查不覆盖汉字数字和非数字论断。
- **链接措辞**：服务端删除回答中谈论“链接/网址”的句子和网址，解决评估第 15 项“不能提供链接”与页面出处矛盾的问题。
- **页面操作**：模型可返回前往节点、下一站、跳过、开始预设路线四类操作，服务端校验节点 ID 与路线键后返回，页面执行；原有固定句式快捷指令保留，模型未配置时仍可用。
- **参观上下文**：页面发送当前路线与已看过的节点 ID，服务端只保留已知 ID 写入系统提示，不接收路线名称等自由文本。
- **追问建议**：每个回答最多附两条不超过 30 字的追问，过滤网址和重复项；页面显示为可点击按钮。
- **换站衔接**：点“下一站”时，小征不再复述左侧正文，改为说明从哪一站来到哪一站、这是路线第几站、还剩几站，并附本站推荐问题。
- **AI 规划理由**：由系统根据实际选中的节点生成，例如“按你的描述，从 14 个节点中选了「中央苏区」「遵义」「吴起镇」”，不展示模型自由撰写的理由。

验证：`npm test` 通过，新增断言覆盖规划理由、chat/off_topic 类型、闲聊含年份降级、数字不符时的校验重试与降级、问题中数字可复述、截断重试、链接句删除、操作校验（合法、非法节点、当前节点、非法路线）、追问过滤、参观上下文只保留已知 ID、按 IP 限流返回 429。Playwright 模拟接口在 1440×900 与 390×844 检查：换站衔接语正确；闲聊回答不显示“提问时的节点”并显示追问按钮，点击后发出该问题；请求体包含路线与已看过节点；“我想看看飞夺泸定桥那段”返回的前往操作使页面切到泸定桥（手机端切回讲解页）；next 操作前进到吴起镇；429 时输入框保留问题；无横向滚动，无非预期控制台错误。

## 检索改进：BM25、同义说法表、检索评估（2026-11-15）

背景：作品已是“智能体式检索增强生成”——模型先调用工具取资料再作答。知识库目前 26 个节点、93 条扩展、15 个故事，约一万字，暂不引入向量检索（规模小、需另接外部服务、对日期人名番号等精确匹配反而不如关键词）。这次只做三项轻量改进。

1. **新增检索评估**（`npm run eval:retrieval`，`scripts/eval-retrieval.mjs`）：40 个查询（关键词式和口语问法都有），每个标注应命中的资料 ID；不调用模型，只测 `search_materials` 工具。指标为前 3 条命中率、前 8 条命中率（工具一次最多返回 8 条）和 MRR。
2. **关键词打分换成 BM25**（字符二元组，k1=1.2，b=0.5，节点名或故事名里出现的片段加权 1.5 倍），本地计算，不依赖外部服务。常见词（如“长征”“红军”）权重自动降低。
3. **同义说法表**：查询里出现一组中的任意一个说法，就把同组其他说法也作为查询词（权重 0.6）。例如“二万五千里／2.5 万里”“爬雪山／夹金山”“三大主力会师／会宁／将台堡”“新三人团／三人军事领导小组”“周总理／周恩来”。

| --- | --- | --- | --- |
| 改进前（二元组出现计数） | 90.0% | 95.0% | 0.850 |
| 改进后（BM25 + 同义说法） | 100.0% | 100.0% | 0.892 |

改进前未命中的两个查询是“爬雪山”（找不到夹金山）和“三大主力会师”（找不到会宁、将台堡），都属于同义说法问题。结果见《检索评估结果-2026-11-15》。

## 联网兜底（2026-11-16）

做法：资料库优先；历史类问题在资料库里查不到出处时，再调用一次带 `deepseek_web_search` 工具的 `deepseek-flash`（不开思考模式）。联网回答单独标注“网络来源 · 未经人工核对”，逐条列出网页的站点名和标题，政府、党史、中央和省级主流媒体以外的站点加注“非权威来源，仅供参考”；没有任何网页出处的联网回答不采用。资料库只答出一部分时，回答下方提供“资料里没有的部分，联网再查一下”按钮。只有页面请求才启用（请求里带 `web`），可用环境变量 `WEB_SEARCH=off` 关闭；问答评估脚本不带该参数，结果不受影响。

实测（本地服务，真实模型）：

| 问题 | 结果 |
| --- | --- |
| 遵义会议什么时候开的 | 资料库回答，未联网 |
| 红二十五军长征从哪里出发、何时到陕北 | 资料库回答，未联网 |
| 宁化妇女“割掉髻子当红军”是怎么回事 | 资料库答出挑粮支前部分并出现“联网再查”按钮；点击后给出网络来源回答，列出 5 个网页（2 个标为权威站点） |
| 宁化 1300 名妇女后来都参加长征了吗（强制联网） | 指出 1300 名是运粮支前、不是参加长征，列出 4 个网页 |
| 今天北京天气怎么样（强制联网） | 拒绝，说明只查证长征相关内容 |

局限：网络来源部分不做数字和书名校验，只保证每条回答有网页出处并标注清楚；一次联网约多花十几秒；权威站点名单按域名后缀判断，较粗。
