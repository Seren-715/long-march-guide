## 真实浏览器联调发现的问题

通过本机鉴权代理访问私有站点，用真实 DeepSeek 测试：遵义会议常委问题返回正确回答和扩展资料链接；随后追问出现模型输出格式异常。已将历史中的助手消息转换为 JSON 输出格式，并对空或无效 JSON 增加最多一次重试；自动测试覆盖首次格式错误后成功和两次错误后返回提示。修复后的线上浏览器复测仍需记录。

2026-11-13 修复后，以本机鉴权代理连接私有站点，用浏览器连续提问遵义会议常委和会议主要问题，均获得回答和来源；再问“为什么重要”时系统保守提示资料不足。切换赤水河后询问一渡和四渡时间，返回与现有资料一致的日期及来源。该结果仅覆盖上述场景。

2026-11-13 后续版本浏览器复测：通过本机鉴权代理连接私有站点，连续询问遵义会议常委、会议处理的问题、会议重要性，均得到回答并显示资料链接；切换到赤水河后询问一渡和四渡日期，也得到与条目一致的回答。该结果为单次抽样，仍需扩展问题覆盖与人工核验。

2026-11-13 本地浏览器模拟问答：通过键盘激活遵义节点后焦点仍停留在该节点；点击建议问题会向当前节点发问，展开依据摘要可见受控条目文本。以上为模拟响应测试，线上真实模型应再复测。

## 自然语言路线规划与草稿保护

本地模拟模型测试：合法三个节点按既定时间顺序返回；非法 ID、重复 ID 和无关偏好分别返回错误；浏览器中模拟成功规划，保留未发送的问答草稿；规划等待时手动前进，旧规划结果不会覆盖新进度。模型规划理由和路线是否真正符合各类偏好仍需真实模型抽样测试；该功能仍可使用预设规则路线。

私有部署 9d0b7d00 真实 DeepSeek 接口抽样：偏好“战役与渡河”返回湘江、赤水河、泸定桥三个节点；完整路线返回九个节点；无关天气问题返回 422。完整路线的模型理由声称“完整呈现长征全过程”，超出本项目资料范围，因此后续修改为由系统提供固定的覆盖范围提示，模型的原始理由不再展示。上述为各一次抽样，不代表所有偏好都可正确匹配。

后续部署版本 913041b9 真实浏览器联调（经本机鉴权代理）：输入“我想了解战役与渡河的艰难历程”，返回湘江→赤水河→泸定桥，并显示资料覆盖有限的固定说明。此前真实接口测试无关天气偏好返回 422。以上分别为单次测试；多样化偏好、模型规划可靠性及实际用户评价仍待进一步验证。
