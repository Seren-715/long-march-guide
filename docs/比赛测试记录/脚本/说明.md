# 测试脚本说明

本目录是生成附录 A、C（P-13 复测）、E 用的脚本和用例，在仓库根目录运行。用到真实模型的需要 DeepSeek 密钥。

| 文件 | 用途 | 用法 |
| --- | --- | --- |
| `explore.mjs` | 按用例文件逐条调用 `/api/chat` 或 `/api/plan`；多轮用例带上签名对话记录；记下回答、出处、处理过程、耗时和自动判定，输出 JSON | `DEEPSEEK_API_KEY=… node docs/比赛测试记录/脚本/explore.mjs <用例.json> <结果.json>` |
| `用例-探索测试.json` | 附录 A 的 44 个用例（A–K、J 类） | 同上 |
| `用例-专项复测.json` | 附录 A 的 12 个专项复测用例（L、X、R 类） | 同上 |
| `用例-P13复测.json` | 附录 C 末尾 P-13 的 4 次复测 | 同上 |
| `robust.mjs` | 接口健壮性 18 项，不调用模型（附录 E2） | `node docs/比赛测试记录/脚本/robust.mjs "$PWD/worker/index.js"` |
| `xss.cjs` | 页面安全检查，用模拟接口（附录 E3）；需先在 4173 端口启动开发服务器 | `node docs/比赛测试记录/脚本/xss.cjs` |
| `realui.cjs` | 真实页面流程，桌面和手机各一次（附录 E4）；需先在 4195 端口启动带密钥的开发服务器 | `node docs/比赛测试记录/脚本/realui.cjs <输出目录>` |

用例文件里的 `expect` 是自动判定条件：`type` 回答类型、`has` 必须出现的正则、`not` 不能出现的正则、`cites` 应引用的资料 ID 之一、`noSources` 不应有馆内出处、`web` 应有网页来源。

开发服务器：

```bash
PORT=4173 DEEPSEEK_API_KEY=local-card-test node scripts/dev.mjs
```

```bash
PORT=4195 DEEPSEEK_API_KEY=你的密钥 node scripts/dev.mjs
```

浏览器脚本依赖 Playwright 和 Chromium。
