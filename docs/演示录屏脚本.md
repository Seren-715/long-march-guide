## 录制前必须核查

1. 用最终 GitHub `main` 与站点发布版本对应的提交号标注测试记录。**GitHub 合并不代表 Sites 已发布该版本**。
2. 同一题至少在 3 个新会话中实测，并记录完整回答、来源链接、是否出现未能核对的数字、总耗时。不能剪辑掩盖错误；实测失败时先修复再录制。
