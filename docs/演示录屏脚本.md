# 演示录屏脚本（工作稿）

建议时长 2—3 分钟，录制前先用最终链接和网络验证问答功能与资料链接，勿展示密钥或后台。

1. 开场：介绍作品名称与目标，说明面向自主学习的互动讲解员。
2. 选择“转折与决策”和精简路线，展示规则生成的节点顺序；点开湘江和遵义，查看讲解与资料出处。
3. 对遵义会议提一个事实问题，再提出一个承接上文的追问；打开回答所附来源，展示资料可追溯。演示前核实回答是否与来源一致。
4. 演示继续、跳过或手动切换节点，说明用户可控制参观进度；对资料覆盖范围外的问题展示系统的谨慎回答（以实测结果为准）。
5. 结束：说明地图为节点示意、回答需核对原文，并展示知识库说明与测试记录。

录屏完成后应完整回看画面、文字、声音和链接，并确认不包含敏感信息。不要将此脚本当作已完成的录屏或测试证明。
