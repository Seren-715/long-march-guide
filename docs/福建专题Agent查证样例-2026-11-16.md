# 福建专题 Agent 查证样例（2026-11-16）

| 用户提问 | 关键检查点 |
| --- | --- |
| 福建有多少人参加长征？ | 要标明使用的来源口径，不能把“近3万”写作精确数量。 |
| 中复村 9 月 30 日与于都河 10 月 17 日哪一个才是长征开始？ | 区分不同部队、出发阶段与渡河事件。 |
| 宁化 1300 名妇女都参加长征了吗？ | 1934 年初的支前劳动不等于全程参加长征。 |
| 红三十四师都是福建人吗？陈树湘籍贯在哪里？ | 辨别主力兵员来源和师长籍贯。 |
| 邓六金在哪一次渡赤水背送伤员？ | 来源未明确，不应猜测具体次数。 |
| 谢小梅、吴富莲都跟主力走到陕北了吗？ | 分别说明途中奉命留在贵州、西路军发生在会师之后。 |
| 蔡威是红四方面军还是中央红军？ | 避免中央红军主线与其他方面军混同。 |
| 杨成武一昼夜奔袭240里是什么意思？ | 区分其中一段急行军与从安顺场到泸定桥的全程。 |
