# 长征路上

长征史料查证助手。观众提问，或贴一句关于长征的说法，助手“小征”查阅有出处的史料、核对后回答，查不到会直接说明。**目前收录的是中央红军主力的长征路线**（中央苏区至吴起镇，共 23 处），另有到陕北之后的直罗镇和红军三大主力会师；红二、红四方面军和红二十五军的长征只有少量资料。地图为示意。知识库包含 26 个节点、93 条扩展资料。

“小征”是一个工具调用智能体：模型自己决定查阅哪些资料（按节点、按编号、关键词检索）、要不要操作页面（打开某一站、下一站、定制路线），回答只能引用本次取出的资料，并经服务端核对出处、数字和文件名；处理过程在对话中实时显示。

## 本地运行

需要 Node.js 18 或更新版本，无需安装额外依赖。

```sh
npm run build
npm test
npm run dev
# 可选：联网核查全部史料链接（目前 47 个）是否可打开
npm run check:sources
```

真实模型评估：按《问答评估清单》逐项调用讲解员接口，生成《问答评估结果-日期》文档，人工判定一栏留空待填。需要 DeepSeek 密钥，或用 `EVAL_BASE_URL` 指向已部署站点：

```sh
DEEPSEEK_API_KEY=你的密钥 npm run eval
```

回答依据审计：用常规题、诱导编造题和多轮施压题检查回答是否只来自知识库，逐句比对所引资料并标出可疑句子，生成《回答依据审计-日期》：

```sh
DEEPSEEK_API_KEY=你的密钥 npm run audit
```

知识库原文比对：抓取每条资料的来源网页，逐句比对资料文字与原文，标出原文中找不到依据的句子（云端环境需加 `HTTP_PROXY="$HTTPS_PROXY" NODE_USE_ENV_PROXY=1`）：

```sh
npm run check:kb
```

本地预览打开 `http://127.0.0.1:4173`。本地预览默认不载入 API 密钥，能浏览页面和路线，模型问答会提示尚未配置；如需在本地试用真实问答，用 `DEEPSEEK_API_KEY=你的密钥 npm run dev` 启动（对话签名密钥自动随机生成，可用 `HOST`、`PORT` 改监听地址）；不要把密钥写入源码或前端。线上密钥由 Sites 服务端环境变量管理，包含 `DEEPSEEK_API_KEY` 和独立随机的 `HISTORY_SIGNING_KEY`；不得写入源码或前端。

## 代码与材料

- `src/data.js`：节点、资料与建议问题。
- `src/page.html`：交互界面。
- `src/stories.js`：长征故事（真人真事），挂在节点上展示，已审核的同时作为问答资料；只收有权威来源的报道或党史叙述，`reviewed` 规则同上。
- `scripts/map/build_map.py`：沙盘鸟瞰图的 Blender 建模与渲染脚本，输出 `src/assets/longmarch-map.webp` 和 `src/map-layout.json`。重新生成：`python -m venv venv && ./venv/bin/pip install bpy numpy && ./venv/bin/python scripts/map/build_map.py`（只更新坐标可加 `--no-render`）。这是地形示意，不画边界、不标行政区。
- `src/server.js`：Worker 请求处理与模型调用。
- `scripts/generate.mjs`：将源文件合成为部署入口 `worker/index.js`。
- `scripts/check-sources.mjs`：联网检查知识库全部来源 URL 的可达性（不替代语义核对）。
- `docs/`：创作文档、知识库说明、测试记录和录屏脚本。
- `deliverables/`：本地生成的演示素材，不作为网站部署文件。

预设路线采用规则生成；精简路线也可由模型根据自然语言偏好在既有节点中选 3 站，服务端校验节点和数量并按时间排序；完整路线由服务端直接按时间顺序返回全部节点。问答不具备全文检索或实时联网功能。模型给出的来源 ID 经白名单检查，但不等于逐句事实核验。多轮历史由服务端签名并绑定页面会话和节点，签名有效期一小时；它不能证明回答事实正确，也不能替代限流。讲解员先判断问题类型：历史问题必须引用资料，回答中的阿拉伯数字须出现在所引资料或用户问题中，否则带校验提示重试一次，仍不合格则降级为“资料不足”；问候和使用说明可不引用资料，但带年份等数字的回复会按历史问题处理。模型还可返回经服务端校验的页面操作（前往节点、下一站、跳过、开始预设路线）和最多两条追问建议，页面会把当前路线与已看过的节点 ID 一并发送。部分人民网频道只提供 http 链接，页面会打开原站；所有链接只来自服务端知识库，不来自模型或用户输入。服务端对模型调用做内存限流：每个 IP 每 10 分钟问答 30 次、规划 10 次，每个运行实例每小时共 600 次，可用环境变量 `CHAT_LIMIT_PER_IP`、`PLAN_LIMIT_PER_IP`、`MODEL_LIMIT_PER_HOUR` 调整；计数只在单个实例内有效、重启清零，无法取得客户端 IP 时只受每小时总量限制，因此不能替代在模型服务账户侧设置费用上限。当前站点保持私有；公开前需另行处理评委访问，并在 DeepSeek 账户设置用量或余额上限。
