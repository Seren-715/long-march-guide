# 长征路上

长征主题互动虚拟讲解员。作品以中央红军主力长征为主线，另展示红军三大主力会师与红二十五军先到陕北；地图为节点示意。知识库包含 14 个节点、27 条扩展资料，规则路线、知识条目和界面均使用 JavaScript，DeepSeek 问答通过服务端 Worker 调用。

## 本地运行

需要 Node.js 18 或更新版本，无需安装额外依赖。

```sh
npm run build
npm test
npm run dev
# 可选：联网核查 34 个史料链接是否可打开
npm run check:sources
```

本地预览打开 `http://127.0.0.1:4173`。本地预览默认不载入 API 密钥，能浏览页面和路线，模型问答会提示尚未配置；不要把密钥写入源码或前端。线上密钥由 Sites 服务端环境变量管理，包含 `DEEPSEEK_API_KEY` 和独立随机的 `HISTORY_SIGNING_KEY`；不得写入源码或前端。

## 代码与材料

- `src/data.js`：节点、资料与建议问题。
- `src/page.html`：交互界面。
- `src/server.js`：Worker 请求处理与模型调用。
- `scripts/generate.mjs`：将源文件合成为部署入口 `worker/index.js`。
- `scripts/check-sources.mjs`：联网检查知识库全部来源 URL 的可达性（不替代语义核对）。
- `docs/`：创作文档、知识库说明、测试记录和录屏脚本。
- `deliverables/`：本地生成的演示素材，不作为网站部署文件。

预设路线采用规则生成；精简路线也可由模型根据自然语言偏好在既有节点中选 3 站，服务端校验节点和数量并按时间排序；完整路线由服务端直接按时间顺序返回全部节点。问答不具备全文检索或实时联网功能。模型给出的来源 ID 经白名单检查，但不等于逐句事实核验。多轮历史由服务端签名并绑定页面会话和节点，签名有效期一小时；它不能证明回答事实正确，也不能替代限流。部分人民网频道只提供 http 链接，页面会打开原站；所有链接只来自服务端知识库，不来自模型或用户输入。当前站点保持私有；公开前需另行处理评委访问与模型费用控制。
