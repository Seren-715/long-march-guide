# 数字长征沙盘（赛道二 · AI 编程）

以红军长征为主题的创意互动网页：行军沙盘（滚动叙事）、四渡赤水示意、四路红军数据图、会议纸带、人物星河、长征故事、知识问答和可保存的“行军卡”。

- **直接打开**：`index.html`（单文件，离线可用）
- **源文件**：`src/`；**构建**：`npm run build:march`；**检查**：`npm run test:march`
- **文档**：[创作文档说明](../docs/赛道二-创作文档说明.md) · [设计文档](../docs/赛道二-设计文档.md)

史实全部取自本仓库知识库的已审核资料；`src/facts.js` 中每个日期和数字都写明资料 ID 与原文片段，构建时逐条核对，找不到原文即中止构建。
